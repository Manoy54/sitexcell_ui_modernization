# Synthetic fixtures

Prototype fixture inputs belong here. `site-context.js` is a local snapshot of the authenticated LAAN Site ID, address, and Site Notes to Carriers mapping used to make the prototype reflect the real form; it must be refreshed when the approved SiteXcell source changes and must not be treated as a production data store.

The fixture set must cover normal and edge states for activities, Sites, dates, uploads, declarations, recovery, and drafts. Existing live-test fixtures under `tests/laan-request/fixtures/` remain unchanged and are not copied into the prototype automatically.
