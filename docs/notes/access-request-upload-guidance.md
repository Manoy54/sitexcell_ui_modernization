# Access Request upload guidance

These annotated screenshots are the visual source notes for the prototype's
qualification upload behavior:

- [Current upload behavior](./image%20copy%202.png) shows the confusing
  concatenated filename, size error and cancellation state.
- [Suggested compact file list](./image%20copy%203.png) shows each file with
  its own Remove action and an explicit validation message.
- [Suggested invalid-file treatment](./image%20copy.png) shows valid and
  invalid files remaining distinguishable without hiding the valid selection.
- [Review note](./image.png) explains why the error should use the form's red,
  compact 12px treatment and why cancellation should remove the file entry.

The prototype applies these notes only to the synthetic **Qualifications &
training** field. Other document fields retain their single-document
contracts. These screenshots are guidance, not production business-rule
approval.
